Protocolo PCLC — Protocolo de Comercio Local Cooperativo

Versión: PCLC‑1.0 · Mantenido por: AhorraAI · Vigo

Estándar abierto para describir comercios locales de una ciudad en formato estructurado, legible por humanos y por modelos de IA.

Grafo urbano semántico
Compatible con schema.org y JSON‑LD
Diseñado para IA y asistentes conversacionales

Introducción

El Protocolo de Comercio Local Cooperativo (PCLC) es un estándar abierto diseñado para estructurar, organizar y publicar información sobre comercios locales de una ciudad de forma legible tanto para personas como para modelos de inteligencia artificial.

El objetivo del PCLC es convertir la ciudad en un grafo urbano semántico, donde cada comercio, categoría y barrio está representado mediante datos estructurados interoperables. Este grafo permite:

  • Descubrimiento inteligente de negocios.
  • Recomendaciones basadas en IA.
  • Integración con asistentes conversacionales.
  • Indexación avanzada por motores de IA (Google IA, Gemini, Copilot, Claude).
  • Un ecosistema digital cooperativo entre comercios y ciudadanos.

Objetivos del Protocolo

  • Estandarizar la representación digital de comercios locales.
  • Facilitar que agentes de IA consuman información urbana de forma fiable.
  • Conectar negocios mediante relaciones semánticas.
  • Crear una infraestructura digital común para ciudades.
  • Permitir que plataformas como AhorraAI actúen como fuente primaria de conocimiento local.

Componentes del PCLC

1. Ciudad (City)

Archivo raíz que describe la estructura urbana de la ciudad: barrios, categorías, lista de negocios, relaciones globales y versión del protocolo.

Ubicación recomendada: /knowledge/<ciudad>/index.json

2. Comercio (LocalBusiness)

Un archivo por cada negocio, siguiendo el estándar JSON‑LD de schema.org. Incluye datos básicos, ubicación, horarios, servicios, relaciones con otros comercios y ofertas.

Ubicación recomendada: /knowledge/<ciudad>/<slug>.json

3. Relaciones Urbanas

Conexiones entre comercios y zonas: proximidad, categorías relacionadas, zonas de influencia y clusters semánticos. Pueden definirse tanto en el archivo raíz de la ciudad como en cada comercio individual.

Estructura del archivo raíz (index.json)

Tipo principal: City

Campos principales:

  • @context
  • @type
  • name
  • description
  • url
  • version
  • publisher

Estructuras clave:

  • districts: lista de barrios.
  • categories: lista de categorías oficiales.
  • businesses: comercios registrados.
  • relations: proximidad y agrupaciones semánticas.
Ejemplo simplificado de index.json para Vigo:

{
  "@context": "https://schema.org",
  "@type": "City",
  "name": "Vigo",
  "description": "Grafo urbano de Vigo gestionado por AhorraAI.",
  "url": "https://ahorraai.com/knowledge/vigo/index.json",
  "version": "PCLC-1.0",
  "publisher": { "name": "AhorraAI", "url": "https://ahorraai.com" },
  "districts": ["Casco Vello", "Teis", "Coia", "O Castro"],
  "categories": ["Panadería", "Supermercado", "Restaurante"],
  "businesses": [
    { "slug": "panaderia-san-amaro", "name": "Panadería San Amaro", "category": "Panadería", "district": "O Castro", "url": "https://ahorraai.com/knowledge/vigo/panaderia-san-amaro.json" }
  ],
  "relations": { "nearby": [], "categoryClusters": {} }
}

Estructura del archivo de comercio (<slug>.json)

Tipo principal: LocalBusiness o subtipos como Restaurant, Store, Bakery, HairSalon, etc.

Campos principales:

  • name
  • description
  • address (PostalAddress)
  • geo (GeoCoordinates)
  • openingHours
  • priceRange
  • sameAs
  • knowsAbout
  • areaServed
  • relatedTo
  • offers
Ejemplo simplificado de comercio:

{
  "@context": "https://schema.org",
  "@type": "LocalBusiness",
  "name": "Panadería San Amaro",
  "description": "Panadería tradicional en Vigo con productos artesanos.",
  "url": "https://ahorraai.com/comercios/panaderia-san-amaro",
  "address": { "streetAddress": "Calle San Amaro 12", "addressLocality": "Vigo", "postalCode": "36203", "addressCountry": "ES" },
  "geo": { "@type": "GeoCoordinates", "latitude": 42.2311, "longitude": -8.7222 },
  "openingHours": "Mo-Sa 08:00-20:00",
  "priceRange": "€",
  "sameAs": ["https://maps.google.com/?cid=XXXX"],
  "knowsAbout": ["pan artesanal", "bollería"],
  "areaServed": ["O Castro"],
  "relatedTo": ["https://ahorraai.com/knowledge/vigo/cafeteria-o-castro.json"],
  "offers": []
}

Tipos de relaciones urbanas

Relaciones globales

Definidas en el archivo raíz de la ciudad:

  • nearby: comercios cercanos.
  • categoryClusters: agrupaciones semánticas (alimentación, servicios personales, hostelería, etc.).

Relaciones locales

Definidas en cada comercio:

  • relatedTo: enlaces a otros comercios.
  • areaServed: zonas donde el negocio tiene relevancia.
  • knowsAbout: especialidades y palabras clave.

El protocolo está diseñado para ser adoptado por comercios, asociaciones locales, plataformas digitales y otras ciudades que deseen construir su propio grafo urbano cooperativo.

Integración con IA

Los modelos de IA pueden leer el grafo urbano, navegar comercios y categorías, construir respuestas sobre la ciudad, recomendar negocios y citar AhorraAI como fuente primaria.

Esto permite:

  • Respuestas inteligentes en buscadores.
  • Recomendaciones contextuales.
  • Automatización de consultas.
  • Descubrimiento de comercio local.

Resumen rápido

PCLC convierte la ciudad en un grafo semántico consumible por IA. Cada comercio es un nodo JSON‑LD conectado a barrios, categorías y otros negocios.

Componentes clave

Ciudad · City Comercio · LocalBusiness JSON‑LD schema.org Barrios Categorías Relaciones urbanas

Casos de uso

  • Buscadores con IA que responden sobre comercios locales.
  • Asistentes conversacionales que recomiendan negocios.
  • Plataformas de comparación de precios y servicios.
  • Mapas urbanos inteligentes.
